# 用 GBC(写给人类)

欢迎使用 GBC。它把"这次改动会不会悄悄碰坏别处"从一种担心,变成可以当场验证的事实:你在意的那些行为
被登记成一条条带测试的**保证**,每次改完一跑——全绿就安心,有红就精确告诉你碰坏了谁、谁在依赖它。

而最好的消息是:**接入 GBC,你几乎不用亲自动手。** 交给你的 coding agent 就好。

## 怎么开始

1. 让你的 agent **安装并运行 GBC 的 `setup-gbc` skill**。
2. 它会就近问你几个问题——用哪个 Python 环境跑 GBC、你的项目怎么跑测试、规则写进哪个文件——
   照实回答即可,不懂的它会先解释。
3. 答完,它就把 GBC 接进了你手头的项目。之后重启一次 agent,就能开始用了。

## 每个项目做一次

GBC 是跟着项目走的,不是装一次就一劳永逸:测试怎么跑、用什么环境,每个项目可能都不一样。所以
**每开一个新项目,让 agent 再跑一次 `setup-gbc` 就好**——同样是几分钟的事。
