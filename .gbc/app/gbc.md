# app —— 工具的 Python 包

实现本体的全部代码。分层自外向内、**依赖只能向内**:`interface`(表面 + 编排/IO)→ `core`
(纯逻辑 + 跑测试)→ `models`(数据契约);`config` 与 `utils` 为横切支撑,被各层使用但不反向依赖业务层。
每个子文件夹有自己的 `gbc.md` 说明意图与内部约束。

## config

配置与进程级状态(项目根、备份份数、executor 配置)。回答"在哪个项目上工作、怎么跑测试"。

## models

跨层共享的数据契约(保证/依赖/验证结果/异常)。无业务逻辑、无 IO。

## core

保证系统引擎 + 测试执行。纯模型操作,不碰路径解析与 `.gbc` 文件 IO。

## interface

cli / mcp 对外表面 + `base` 编排/IO。换表面不动引擎。

## utils

原子写文件、json↔模型、`.gbc` 路径映射等横切工具,无业务语义。
